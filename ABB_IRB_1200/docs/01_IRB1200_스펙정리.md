## 3. 툴 플랜지 (6축 끝단) 규격

```
플랜지 외경 (파일럿 보스) : Ø40 h7  (-0 / 0.025)
센터 구멍                : Ø20 H7  (+0.021 / 0)
로케이팅 핀홀            : Ø5  H7  (+0.012 / 0), 깊이 6mm
볼트                     : M5 × 4개, 90° 간격, 45° 오프셋
볼트 PCD                 : Ø31.5
볼트 체결 깊이           : 6mm
볼트 등급                : 12.9 (필수)
```

> 스펙 문서 39페이지 (Robot tool flange 도면 참조)

```
브라켓 센터 보스 내경    : Ø39.5~39.7mm (FDM 공차 여유)

로케이팅 핀 위치        : 45° 오프셋 기준 0° 위치
```

## 4. 관성 모멘트 제한 (6축)

```
J6 = Mass × L² + J0z ≤ 0.2 kgm²
L = 플랜지 중심에서 무게중심까지 수평거리 (m)
```

| 팔 길이 | 툴 질량(×4) | J6 추정 | 판정 |
|---|---|---|---|
| 150mm | 500g | ~0.045 kgm² | ✅ 여유 |
| 200mm | 500g | ~0.080 kgm² | ✅ 양호 |
| 250mm | 500g | ~0.125 kgm² | ⚠️ 주의 |
| 300mm | 500g | ~0.180 kgm² | ❌ 한계치 |

**→ 크로스 브라켓 팔 길이 200mm 이내 권장**

## 5. 공압 (내장 배관)

```
베이스 입력   : R1/8" × 4포트
어퍼암 출력   : M5 × 4포트, 최대 5 bar
```
별도 외부 배관 없이 어퍼암 M5 포트에서 직접 분기 가능.
