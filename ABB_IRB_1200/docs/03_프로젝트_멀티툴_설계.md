# 멀티툴 엔드이펙터 프로젝트 설계 메모
> ABB IRB 1200 6축 브라켓 기반 공압 멀티툴 시스템

---

## 1. 프로젝트 컨셉

6축 끝단에 십자형 브라켓을 부착하고, **6축 회전으로 툴을 선택**하는 방식.
작업 위치(특정 방향)에 온 툴이 캠 메커니즘에 의해 자동으로 ~50mm 돌출.

```
툴 선택  : 6축 회전 (0° / 90° / 180° / 270°)
툴 돌출  : 캠 + LM 가이드 + 스프링 복귀 (패시브 기계식)
툴 제어  : 솔레노이드 밸브 → 어퍼암 내장 공압 포트 활용
```

---

## 2. 브라켓 설계 제약

### 플랜지 인터페이스
| 항목 | 값 |
|---|---|
| 센터 보스 내경 | Ø39.5~39.7mm |
| M5 heat-set insert 홀 | Ø6.4mm, 깊이 8mm |
| 볼트 PCD | Ø31.5mm |
| 볼트 배치 | 4개, 90° 간격, 45° 오프셋 |
| 로케이팅 핀 | Ø5mm, 각도 기준 필수 |

### 관성 모멘트 예산
```
J6 ≤ 0.2 kgm²
팔 길이 200mm, 툴 1개 400g 기준 → J6 ≈ 0.064 kgm²  ✅
```

### 3D 프린팅 재료
- **PETG 권장** (내열 80°C, 충격 양호)
- ABS 가능 (내열 100°C, 아세톤 후가공)
- PLA 금지 (내열 60°C, 취성)

---

## 3. 툴 구성 (4개)

| 위치 | 툴 | 공압 채널 |
|---|---|---|
| 0° (상단) | 진공 흡착 그리퍼 | CH1 |
| 90° | 접착제 디스펜서 | CH2 |
| 180° | 압착 / 프레스 툴 | CH3 |
| 270° | 비전카메라 + 마킹 | CH4 |

---

## 4. 돌출 메커니즘 — 캠 + LM 가이드

```
[로봇 5축 하우징] → 고정 캠 디스크 볼트 고정 (회전 안 함)
[6축 브라켓]      → 캠 팔로워 베어링이 캠 위를 구름
                     → LM 가이드 슬라이드로 직선 변환
                     → 스프링 복귀
```

### 캠 프로파일
- 작업 위치(1곳): 높이 +50mm
- 나머지 3곳: 높이 0mm
- 전환 경사각: 30° 이하 (충격 방지)
- 최고점 평탄 구간: 최소 15° (작업 중 위치 유지)

### 구매 부품 (필수)
| 부품 | 스펙 | 비고 |
|---|---|---|
| M5 heat-set insert | M5, OD 6.4mm | 개당 200~300원 |
| MGN9 LM 가이드 | 레일 150mm + 블록 | 개당 7,000~10,000원 |
| 캠 팔로워 베어링 | M5 나사 타입 | 개당 2,000~5,000원 |
| 복귀 스프링 | 압축스프링 (계산 후 선정) | |
| M5 볼트 | 등급 12.9 | 플랜지 체결용 |

### 3D 프린팅 범위
- 브라켓 메인 바디
- 캠 디스크 (PTFE 테이프 부착으로 마찰 저감)
- LM 마운팅 블록
- 툴 홀더 하우징
- 케이블/호스 가이드

## 5. 두께 / 단면 가이드

| 부위 | 권장값 |
|---|---|
| 베이스 플레이트 두께 | 12~15mm |
| 베이스 외경 | 80~100mm |
| 볼트홀 엣지 살 두께 | 최소 5mm |
| 암 뿌리 단면 | 20×20mm (실선) 또는 25×20mm 박스 |
| 암 끝단 단면 | 15×15mm |
| 인필 — 베이스 | 100% |
| 인필 — 암 뿌리 30mm | 100% |
| 인필 — 암 중간~끝 | 40~60% |

### 출력 방향
- 베이스 플레이트: **눕혀서** 출력 (M5 볼트 인발력 최대화)
- 암: **세워서** 출력 (굽힘 하중에 레이어 직각)

---

## 6. 공압 배선

```
로봇 베이스 R1/8" 입력 (4포트)
    ↓ 내장 배관
어퍼암 M5 출력 (4포트, Max 5 bar)
    ↓ 짧은 튜브 (OD 4mm)
6축 브라켓 솔레노이드 밸브 4개
    ↓
각 툴 공압 실린더
```

솔레노이드 밸브 사양: DC 24V (ABB 컨트롤러 DO 출력과 일치)

---

## 7. RAPID 제어 코드 패턴

### 툴 선택
```rapid
PROC SelectTool(num toolNum)
    VAR jointtarget cur;
    cur := CJointT();
    cur.robax.rax_6 := toolNum * 90;
    MoveAbsJ cur, v100, fine, tool0;
ENDPROC
```

### 솔레노이드 밸브 제어
```rapid
SetDO DO_Tool1, 1;   ! 툴1 공압 ON
WaitTime 0.5;
SetDO DO_Tool1, 0;   ! 툴1 공압 OFF
```

### 작업 위치 이동 (6축 고정)
```rapid
VAR jointtarget work_pos;
work_pos := CJointT();
work_pos.robax.rax_6 := 0;   ! 6축 고정

! 이후 모든 이동에서 rax_6 = 0 유지
MoveAbsJ work_pos, v200, fine, tool_bracket;
```

## 8. 주의사항

1. **LoadIdentify 서비스 루틴** 실행 필수 — 브라켓 + 툴 질량/무게중심 등록
2. **RobotStudio 시뮬레이션** 먼저 — MoveAbsJ 경로 충돌 확인
3. **캠 링 고정 방향** — 로케이팅 핀 위치 기준으로 정렬 후 볼트 고정
4. **6축 ±242° 한계** — 툴 전환 시 최단 경로로 회전하도록 RAPID 설계
5. **브라켓 질량 입력** — RAPID `tooldata`에 정확히 입력해야 모션 성능 보장
