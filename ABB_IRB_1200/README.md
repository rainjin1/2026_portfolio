## 프로젝트 개요

ABB IRB 1200의 6축 끝단에 3D 프린팅 십자형 브라켓을 장착하고,  
**6축 회전으로 툴 선택 + 캠 메커니즘으로 툴 자동 돌출**하는  
멀티툴 엔드이펙터 시스템 구현.

- 툴 1: 진공 흡착 그리퍼
- 툴 2: 접착제 디스펜서  
- 툴 3: 압착 / 프레스
- 툴 4: 비전카메라 + 마킹
