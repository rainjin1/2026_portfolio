# 로봇 운용 체크리스트
> ABB IRB 1200 / FlexPendant / OmniCore 기준

---

## 1. 시작 전 체크

- [ ] 제어부 메인 스위치 ON
- [ ] 비상정지 스위치 해제 확인 (교시부 + 제어부)
- [ ] 안전 문 / 안전 회로 (Run Chain) 이상 없음
- [ ] 모터 ON 스위치 → 모터 ON 상태 확인

---

## 2. 모드 선택

| 모드 | 최고속도 | 용도 |
|---|---|---|
| 수동 (Manual) | 250 mm/s | 프로그램 작성, 티칭, 테스트 |
| 자동 (Automatic) | 무제한 | 실제 운전 |

> 수동 모드에서 로봇 움직이려면 **Enabling Device (3단계 스위치)** 중간 위치 유지 필수

---

## 3. 조깅 방법

| 버튼 | 동작 |
|---|---|
| 축선택 (1회) | 개별축 1-3 제어 |
| 축선택 (2회) | 개별축 4-6 제어 |
| 선형이동 | 베이스 좌표계 직선 이동 |
| 자세변경 | 툴 자세만 변경 |

---

## 4. 프로그램 실행 순서

1. 주메뉴 → 프로그램 편집기
2. 프로그램 작성 또는 로드
3. 디버그 → **PP를 메인으로 이동**
4. 모터 ON (Enabling Device 중간 위치)
5. 단축키 **시작 (▶)** 버튼

---

## 5. TCP 설정 (툴 등록)

1. 주메뉴 → 조깅 → 툴 좌표계
2. 새 툴 만들기 → 이름 지정
3. 4점법 또는 5점법으로 TCP 측정
4. 질량 / 무게중심 수동 입력 또는 **LoadIdentify 서비스 루틴** 실행

> **브라켓 장착 후 반드시 LoadIdentify 실행** — 미입력 시 모션 이상, 보증 불가

---

## 6. 영점 조정 (회전 카운터 갱신)

배터리 교체 또는 모터 교체 후 필요:
1. 주메뉴 → 영점 조정
2. 각 축을 캘리브레이션 눈금에 맞춤
3. 회전 카운터 갱신 실행
4. 재시작

---

## 7. 주요 이벤트 로그 코드

| 코드 | 의미 | 조치 |
|---|---|---|
| 10010 | 모터 OFF 상태 | 모터 ON 스위치 |
| 10013 | 비상정지 상태 | 비상정지 해제 후 모터 ON |
| 10020 | 실행 오류 | 이벤트 로그 확인 후 PP 메인 이동 |
| 10024 | 충돌 감지 | 수동 모드로 후퇴 후 재시작 |
| 10036 | 회전 카운터 미갱신 | 영점 조정 실행 |

---

## 8. FlexPendant 터치 오류 시

1. 전원 OFF
2. **4번 버튼 + 정지 버튼** 누른 채로 전원 ON
3. 재시작 후 터치 캘리브레이션 실행
4. 조이스틱 캘리브레이션 실행 (필요 시)
5. 재시작

---

## 9. 백업

- 주메뉴 → 백업 및 복원 → 백업
- 프로그램 수정 전 반드시 백업 권장
- 확장자: `.pgf`

---

## 10. 작업 영역 제한 설정

베이스 좌표계 기준 큐브(P1 하한 / P2 상한)로 작업 영역 정의.
금지 영역 내부/외부 선택 가능.
→ 브라켓 충돌 방지 영역 설정 시 활용
